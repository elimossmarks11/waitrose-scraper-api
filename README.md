
# Waitrose Web Scraper and API

## What This Project Does

This project scrapes, classifies, and serves data on Waitrose frozen/grocery products to estimate what proportion of a UK supermarket's range is **ultra-processed food (UPF)**, using the NOVA classification system. It has two parts:

- **Part A — Scraper** ([scraper/](scraper)): A Scrapy spider (backed by Selenium for JS-rendered pages) crawls Waitrose category and product pages, extracting product name, barcodes, price, and hierarchical category from embedded `__NEXT_DATA__` JSON. Duplicate products (same name, different weights) are merged by barcode. Output is written as JSONL to `data/scraped/products.jsonl`.
- **Part B — Enrichment & API** ([api/](api)): [run_pipeline.py](run_pipeline.py) enriches each scraped product with a NOVA group (1–4, or "Not UPF") via a fallback chain — OpenFoodFacts barcode lookup, then Markers of Ultra-Processing (MUP) ingredient matching, then category inference — and writes the result to `data/enriched/products.jsonl`. That file is then loaded into a SQLite database (`data/enriched/products.db`), which a FastAPI application queries to serve endpoints for browsing, filtering, flagging, and finding non-UPF alternatives to products.

## Environment Setup

Create the conda environment:

```bash
conda env create -f environment.yml
```

Activate it:

```bash
conda activate food
```

If `environment.yml` changes, update your environment:

```bash
conda env update -f environment.yml --prune
```

## Running the Full Pipeline

With the `food` environment activated, run each stage from the project root in order:

```bash
# 1. Scrape Waitrose (writes data/scraped/products.jsonl)
cd scraper
scrapy crawl waitrose
cd ..

# 2. Enrich scraped products with NOVA classifications (writes data/enriched/products.jsonl)
python run_pipeline.py enrich-open-food-facts --all

# 3. Build the SQLite database (writes data/enriched/products.db)
python run_pipeline.py build-db

# 4. Serve the API
python run_pipeline.py serve
```
